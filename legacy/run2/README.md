# Earlier multi-model experiment material

`code/` contains the earlier training and probe implementation. It can be used to run new model/probe comparisons; the figures below use the reported aggregate values.

`reported_model_rates.csv` and `reported_probe_rates.csv` contain the manuscript figure values rather than newly computed outcomes. Rates are percentages. The model figure plots the zero-control case using an uncertainty upper bound; the CSV retains its reported observed rate of zero.

The earlier model/probe figures use the reported constants above. The fine-tuned checkpoint in this release belongs to the later capacity sweep.
